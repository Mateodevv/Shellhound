# Geographic reference data

`iso3166-1.json` and `iso3166-2.json` are unmodified copies from
[pycountry](https://github.com/pycountry/pycountry/tree/main/src/pycountry/databases),
retrieved 2026-09-11. The data originates from Debian's iso-codes project.
The LGPL 2.1 license is retained in `LICENSES/pycountry-LGPL-2.1.txt`.
Shellhound uses these files locally for country and first-level subdivision choices.
