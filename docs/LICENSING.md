# Shellhound licensing

Shellhound uses the custom [Shellhound Source Available License 1.0](../LICENSE)
for material expressly offered under those terms, alongside the continuing
[Apache-2.0 license](../LICENSES/Apache-2.0.txt) for previously licensed material.
Third-party components retain their own licenses; see [NOTICE](../NOTICE).

## What the new license permits

| Activity involving covered material | Permission |
| --- | --- |
| Personal use, research, teaching, internal company use | Allowed |
| Paid investigations and incident response for clients | Allowed |
| Delivering or charging for reports, findings, and evidence exports | Allowed |
| Private changes and free redistribution under the license conditions | Allowed |
| Paid training, installation, and support for the customer's own installation | Allowed under section 2(d) |
| Selling or renting Shellhound or a modified version | Separate written permission required |
| Including Shellhound in a paid software bundle | Separate written permission required |
| Paid hosted access, self-service analysis, or API access | Separate written permission required |

A forensic provider may run Shellhound for a paying client and deliver the
results, including through a results portal. Charging clients to use a hosted
Shellhound interface or analysis API requires a separate agreement. Paying a
general-purpose cloud provider to host your own installation is allowed.
The license text controls if this summary and the license differ.

## Transition and earlier versions

The licensing transition is recorded on 2026-09-08. The repository baseline
immediately before this change is commit
`d78687759d2a6add6bfe77118c70fb3e71a5b8ac`.
That baseline used Apache-2.0. Its original LICENSE file, including its
attribution, is retained byte-for-byte in `LICENSES/Apache-2.0.txt`.

**No Apache permissions are withdrawn.** Material already made available under
Apache-2.0 remains usable, modifiable, and commercially redistributable under
that license, including when copied from this repository later. This includes
third-party contributions received under Apache-2.0. Merely replacing the root
LICENSE cannot make existing Apache material exclusive or stop its resale.
This baseline is a record, not an assertion that no other versions or changes
have been offered under Apache-2.0 elsewhere.

The new terms govern new copyrightable material expressly offered under them
by a rights holder entitled to do so. Preserve existing file-specific notices
and identify differently licensed material when adding it. New original
contributions should explicitly confirm the new license in their pull request;
do not assume an older or pending contribution has been relicensed. Submitting
a contribution does not transfer copyright to the maintainer.

For a mixed distribution, the package metadata lists both licenses using
`Apache-2.0 AND LicenseRef-Shellhound-Source-Available-1.0`. This describes
separately licensed material in one distribution; it does not add restrictions
to independently Apache-licensed code. The license texts and NOTICE must travel
with distributions. Historical release notes continue to identify Apache-2.0.

## Commercial permissions and legal review

For a separate commercial agreement, contact the project maintainer through
the [Shellhound repository](https://github.com/Mateodevv/Shellhound).
Any agreement must cover the relevant rights holders; maintainer status alone
does not establish ownership of every contribution or dependency.

The custom license is a project-specific text prepared for the requested usage
policy. It has not been reviewed by legal counsel and is not a promise of
enforceability. Before publishing a release under these terms or signing an
exclusive agreement, obtain legal review of the wording, contributor rights,
employment-related rights, and compatibility with included components.
