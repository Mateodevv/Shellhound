# Geist Sans

Unmodified variable WOFF2 fonts from the official Geist v1.7.2 release:
https://github.com/vercel/geist-font/tree/v1.7.2/fonts/Geist/webfonts

- `Geist[wght].woff2` is stored as `Geist-Variable.woff2`.
- `Geist-Italic[wght].woff2` is stored as `Geist-Italic-Variable.woff2`.

Copyright and the original SIL Open Font License 1.1 are included in `OFL.txt`.
The application serves these files locally; no external font service is used.
